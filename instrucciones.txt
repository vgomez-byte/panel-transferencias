==============================
PANEL DE SEGUIMIENTO DE TRANSFERENCIAS
==============================

1. Abrir una terminal en la carpeta del proyecto.

2. Activar el entorno virtual
venv\Scripts\activate

3. Copiar el archivo Excel actualizado en la carpeta:
datos\
(Reemplazar el archivo anterior si corresponde).

4. Cargar el archivo a Supabase
python scripts/cargar_csv_supabase.py

Esperar hasta que aparezca el mensaje:
IMPORTACIÓN TERMINADA

5. Ir a la carpeta src
cd src

6. Ejecutar el panel
streamlit run panel_transferencias.py

7. Abrir el navegador
http://localhost:8501
